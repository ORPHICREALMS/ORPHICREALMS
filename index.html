No account or database is used. This browser keeps a local history cache, while the live server's shared message history is temporary and can clear when the free service restarts. The Buddy key is held only in the current page's memory; it is not saved to browser storage or a database. When you message Buddy, the key is sent to your realms.chat server over HTTPS and then to the selected provider. Only enable Buddy if you understand your provider's API billing; the Communicator itself does not require a paid tier. Your server must allow the provider hostname via BUDDY_ALLOWED_HOSTS.
